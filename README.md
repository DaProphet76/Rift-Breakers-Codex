# Rift Breakers

This repository is the working source for the Rift Breakers trilogy, its world atlas, and future supporting novels.

## Current authority

- LEGACY contains the complete previous repository structure.
- Nothing inside LEGACY governs the new project unless it is reviewed and migrated.
- Current canon must live outside LEGACY and follow project/canon-rules.md.

## Main areas

- project — governance, standards, and working rules.
- series — trilogy-wide planning and future-series direction.
- manuscripts — prose, chapter plans, and book drafts.
- atlas — the encyclopedia of the world.
- continuity — timelines, revelation control, and contradiction tracking.
- future-novels — concepts reserved for supporting novels.
- templates — approved file templates.
- research — outside references and inspiration notes.
- assets — project media and supporting artwork.

## Build order

1. Establish project governance.
2. Define the trilogy spine.
3. Approve templates.
4. Build the atlas framework.
5. Audit and migrate usable material from LEGACY.
6. Plan Book One.
7. Rewrite the manuscript.
