# Repository Guide

## Root folders

### LEGACY

The preserved Version 1 repository. Reference only. Nothing here is current canon unless migrated.

### project

Project governance, writing standards, naming rules, workflows, and repository instructions.

### series

The trilogy spine, book purposes, themes, long character arcs, and overall ending.

### manuscripts

Reader-facing prose and chapter planning, separated by book.

Planned structure:

- book-01-ignorance
- book-02-disruption
- book-03-revelation

### atlas

The single-source encyclopedia for characters, families, nations, factions, locations, artifacts, creatures, systems, history, cultures, and terminology.

### continuity

The master timeline, revelation map, character-state tracking, open questions, and contradiction log.

### future-novels

Supporting-novel concepts that are intentionally outside the core trilogy.

### templates

Approved structures for every governed file type.

### research

Inspiration, comparisons, and outside research. Research is never canon by itself.

### assets

Images, maps, music references, and other supporting media. Large working files should not be duplicated throughout the repository.

## Workflow

1. Record or update the governing canon.
2. Update trilogy or book planning.
3. Draft the relevant manuscript section.
4. Check continuity and planned revelations.
5. Update affected atlas entries.
6. Commit the related files together.

## Naming standard

- Folder and file names use lowercase letters and hyphens.
- Each concept has one permanent path.
- Chapter files use two-digit numbering, such as 00-prologue.md and 01-chapter-title.md.
- Superseded current files are marked deprecated rather than given confusing filenames.
- Historical drafts belong only in LEGACY or Git history.
